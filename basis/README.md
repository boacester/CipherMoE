# Select-and-Apply 候选

目标接口：

```text
SelectApply(Enc(e), Enc(x), {W_i}) -> Enc(W_e x)
```

构造应保护路由，在线不需要客户端中间交互。减少完整加密权重的存储，与减少
密码学计算，需要分别验证。

## 联合查表

`fused_lut.cpp` 合并有限精度 expert ID 和标量 activation，直接查表输出乘积。
统计 EvalFunc 调用和依据上游实现推导的内部 PBS 数量，并探索半域填充和负循环
扩展。输入使用 FHEW，首轮排除 CKKS 转换。标量融合成功不等于高维 MoE 稀疏计算成立。

## 共享基优化

`basis_apply.cpp` 使用离线分解 `W_i ≈ Σ_r a[i,r] B_r`，秘密选择少量系数，
应用共享明文基矩阵，再聚合输出。它不构造完整加密权重，但保留每个基输出的
密文门控乘法。收益取决于基的数量和近似误差，实验同时包含随机与共享结构权重。
